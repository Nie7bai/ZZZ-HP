## 编写约定

- 每份规格文档聚焦一个主题，使用清晰、稳定的文件名。
- 明确说明目标、适用范围、非目标、具体行为和验收标准。
- 涉及接口、数据结构或异常处理时，记录关键约束和边界条件。
- 已由其他文档或代码维护的事实应通过链接引用，避免重复定义。
- 需求或实现行为发生变化时，同步更新对应规格文档。
