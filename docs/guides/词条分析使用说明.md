# 词条最优分配 · 使用说明

> **给使用者看**：只讲怎么用、怎么读结果，不讲实现。
> **范围**：只讲「词条分析」区里的**求最优分配**（含它结果区的「曲线」页签）。
> **不在这里**：「扫掠柱图」是同一区里的另一个功能；「收益表」也是平级功能 —— 三者互不依赖。
> 最后更新：2026-09-17

---

## 0. 它是做什么的

你给**固定的「总词条数」**，在词条库里挑条目、分配档数，让**总伤害最高**。

---

## 1. 使用

1. 给要算的角色**导入局外面板**：顶部「导入」里有「**面板导入**」和「**词条导入**」两种（平级，**算的是激活那一份**）。
   没有面板也能跑，但基线是 0 → 无意义（详见 附录2）。
2. 可选，更改词条库设置（详见 2 词条库设置）。
3. 定好「**总词条数**」。
4. 选搜索预设，建议快速或均衡。（详细设置见 3 最优分配高级设置。）
5. 点「**求最优分配**」或「**游戏专用规则分配**」（详见 2 词条库设置）。

## 2 词条库设置

「**词条库**」中的设置可以做什么：

| 名称 | 效果 | 备注/用例演示 |
| --- | --- | --- |
| 勾选 | 没勾的条目等于不存在 | 收益表可隐掉无收益的词条 |
|  |  | 最优分配会筛掉低收益的词条(占用极低的开销) |
|  |  | 因此，你只需要取消勾选有一定收益，且不希望参与计算和显示的词条 |
| 单词条上限 | 这一条最多能投几档（`0` = 不限）； | 根据主观判断，选择单词条上限 |
|  |  | 游戏规则的单词上限是单盘5词条(5档) |
|  |  | 但游戏中有着同词条强化概率降低的隐藏规则 |
|  |  | 结合实际，可选择20左右 |
|  |  | 如果想要数据分析，不选上限 |
| 组额度 | 组内所有条目的档数之和上限 | 默认方案已对 2号位 4/5/6号位的组做了1上限的限制 |
|  |  | 在做特殊的数据分析时才会用到 |
| 高级编辑 | 可以驱动盘中刷不存在的词条 | 可增加局内攻击的增益，与其他词条做配比分析 |

点「**游戏专用规则分配**」会使一套定制的词条库方案和计算规则，会模拟 4/5/6 号位选到攻击/暴击等主属性与副词条重复时造成的总词条数损失。此方案仅加入了游戏中存在的词条条目，对组额度和高级设置进行限制。（详见 附录1）

### 2.1 词条库的新建和保存

官方预设在服务器上、仅由管理员维护。你新建时可以复制其中的预设方案用于快速创建； 新建后存于本机浏览器，后续由你维护。

## 3 最优分配高级设置

如不想了解，选 快速 或者「**均衡**」即可。
速度越慢，则测试的组合越多，越接近穷举，越不容易遗漏最优配比组合。

| 名词 | 一句话 |
|---|---|
| **初始候选门槛（%）** | 开跑前筛**条目**：先只看"这条再加 1 档"能涨多少，低于**本组最高值的这个比例**的直接出局。调高 = 更激进（跑得快、可能漏） |
| **候选兜底（每组前 N 名）** | 每组按"加 1 档"的收益排前 N 名**一定保留**（只救有正收益的）—— 专门挡住「现在不值钱、终局里最值钱」的条目被门槛误杀 |
| **路线保留比例（%）** | 搜索途中筛**分法**：每一层只留"累计提升 ≥ 本层最佳 × 这个比例"的分法 |
| **最小 / 最大保留路线** | 上面那道比例筛完的保底与截顶：不足最小就补足，超过最大就砍掉 |
| **穿透专路** | 单独跑一条"锁住穿透率 / 固定穿透"的路线，再和普通路线比总伤 —— 因为穿透在游戏里是稀缺上限 |

> 门槛 vs 比例的区别：**门槛筛条目**（开跑前一次），**比例筛分法**（每层反复）。

## 3.1 最优分配的局限

提问：这个功能一定能拿到最优的分配吗？
答：对于截止今日的游戏内的配队，可以，但数据层面上不能。

原因见本章。

拿到最优分配的最好办法是穷举，但**穷举在这里不可行** —— 组合数是天文数字：

- 词条库默认 39 条、总词条数 30 档时，光「每条各分几档」的方案数就有 **C(68,38) ≈ 1.8×10¹⁹** 种；
- 只看副词条那 10 条、只分 26 档，也有 **C(35,9) ≈ 7.1×10⁷** 种；
- 而**每一种都要完整算一次伤害**：项目自己的实测（游戏专用四袋：5816 次引擎调用 / 121 秒）≈ **21 毫秒/次** —— 7.1×10⁷ 种 × 21ms ≈ **17 天**，全空间更是 10¹⁰ 年量级。

因此我们需要在开销尽可能少的前提下，拿到最优的那条

核心思路：

1. 在穷举之前，筛选掉没有竞争力的词条，避免大量的试算。

    —— 这就是「高级设置」里的两件事：**初始候选门槛**（每条先"只加 1 档"看**组内**收益，低于「本组最高值 × 门槛」的直接出局 —— 开跑前只筛一次，很快）和**候选兜底（每组前 N 名）**（每组再保底留前 N 名、只救正收益的，专门挡住「现在不值钱、终局里最值钱」的条目被误剪，典型就是副词条爆伤）。

2. 筛完之后**也不是穷举**：搜索本身是**束搜索** —— 每一层只留「累计提升 ≥ 本层最佳 × **路线保留比例**」的分法，再用**最小 / 最大保留路线**兜底与截顶。

3. 全程还有**预算（计算量）**当刹车：花完就停、输出当时最好的那条。

> 所以"最优"的准确读法：**在给定参数与预算下，搜索到的最好解**，不是数学证明的最优。
> 代价是"可能漏"：门槛会误剪条目、比例与最小/最大保留会砍掉分法、预算可能提前花完。
> 当前质量证据：合成场景（8 命中 + 号位额度）三档预设都是 100%；真实 fixture 只验过关键档位，**没有按预设逐档跑完整对照**（见 `dev-docs/TODO.md` T19）。
> 想更接近穷举：门槛调低（`0` = 只丢负收益）、兜底调大、比例调低、最小/最大保留调宽、预算调大 —— 代价是慢。

| 情况                        | 会发生什么                                                   |
| --------------------------- | ------------------------------------------------------------ |
| 词条库**没勾**某条          | 它**等于不存在**，不会被考虑 —— 觉得"明明这条更好"时，先回去看勾选 |
| **面板没导入**              | 功能能跑，但基线是 0 → 收益数字**没有意义**（另外，伤害页本身没面板也不出伤） |
| **预算给小** / **门槛调高** | 用质量换速度，结果可能**不是最优**                           |
| 它求的是**数学最优**        | **不校验游戏里刷不刷得出来** —— 不保证真实配装可行           |
| 与收益表 / 曲线的关系       | 三者**平级**，不是"先看收益表再求最优"；但它们**读同一份词条库**，改库会同时影响 |
| 「游戏专用规则分配」        | 另一套口径（付费判定 + 口袋），结果与普通求最优**不可直接比** |

## 4. 结果怎么读

- **结果表**：按「**组优先**」排序；每条给出分到的**档数**与收益。
- **被上限卡住的条目**：表里会直接写「**已达上限**」并说明原因（不用自己猜）。
- **结果区两个页签**：
  - **曲线** —— 看单个条目"再多投 n 档"的收益走势（当前是**组内对比**，跨组混画没有可比性）；
  - **过程** —— 看搜索是怎么走的。
- **质量信号**（决定要不要重跑）：
  - **预算打满没有**：没打满说明是"自然跑完"，打满了说明是"被迫停"；
  - **搜索没走完** vs **走完了只是没做最后微调** —— 两者含义不同，前者结果更可疑；
  - **「已过期」**：结果被标这个就是**不可信了**，要重新求。

**什么时候会变成「已过期」**：改了**总词条数**、**中止**求解、或**改动了词条库**（含每条的单词条上限 —— 那会改变求解输入）。

## 5. 常见坑

1. **面板有两份**（面板导入 / 词条导入），**算的是"激活"那一份**。数字不对，先看这里。
2. **改了词条库要重求**：勾选、单词条上限、组额度都会改变输入；结果会被标「已过期」。
3. **别拿"游戏专用规则分配"的结果跟普通求最优比**：输入口径不同（付费与口袋），数字不可比 —— 见 附录1。

## 附录1 游戏专用规则分配（详细说明）

它是「求最优分配」旁边那个独立按钮。规则**写死在代码里**，**不看你的词条库** —— 你的库怎么改都不影响它。

**为什么要单独做一套**：游戏里主属性和副词条**不会重复** —— 选了某个 4 号位主属性，副词条池里同名字段就少一条。这套规则把这个代价算进去，更贴近「真实能刷出来的配装」。

**它固定包含 38 条**：4 号位 6 / 5 号位 5 / 6 号位 6 / 2 件套 11 / 副词条 10，默认**全部勾选**。

**付费判定**（按槽位，不看名字）：

| 槽位 | 付费 | 不付费 |
|---|---|---|
| **4 号位** | **全部 6 条**（爆伤 / 暴击 / 攻击 / 生命 / 精通 / 防御） | 无 |
| 5 号位 | 攻击 / 生命 / 防御 | 增伤 30%、穿透率 24% |
| 6 号位 | 攻击 / 生命 / 防御 | 异常掌控 / 冲击力 / 能量恢复 |

**付费的两个代价**（这就是它和普通求最优最大的区别）：

1. **一档多花预算**：付费主属性每档占用 = `1 + x`（`x` 默认 **1**，弹窗里可调 0–20）；
2. **挤占副词条上限**：只要那条付费主属性被投了 **≥ 1 档**，对应的副词条上限就 **−5**。

**组额度也是写死的**：4 / 5 / 6 号位与 2 件套**每组只能选 1 条**；副词条组额度 = **总词条数 − 4**（给上面四个组各留 1 档的位置）。

**弹窗里能改的只有三样**：`x`（付费额外占档）、勾选参与哪些条目、**所有副词条条目上限**（默认 30，`0` = 无上限）。

⚠️ **不要拿它的结果和普通求最优比** —— 输入口径不同，数字不可比。

## 附录2 面板导入（扩展阅读）

- 每个角色存**两份平级**的局外面板：**面板导入** / **词条导入**，**激活哪份就用哪份**算。
- 「词条导入」那份额外承载 4/5/6 号位主属性，供词条相关规则使用。
- **没有面板**时无法使用：局外面板按 0 处理 → 伤害页不出伤；最优分配本身仍可运行（但没有基线）。
- 切换激活份：在「局外面板」块标题行点那两枚胶囊；顶部槽位卡片右侧那枚红标签显示的就是**当前生效**的那份。
