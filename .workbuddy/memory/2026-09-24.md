- 工具环境备注：本机 Git Bash 的 `ls/head/dirname` 不可用，PowerShell 工具调用又不回显 stdout；列目录/查文件请用 Glob/Grep 工具。
- 补充（验证有效）：**git 命令走 Bash 工具能正常回显 stdout**，只是 shim 会在 stderr 打 `dirname: command not found` / `cd: null directory`，属噪音不影响结果。所以查分支/status/log 优先用 Bash 工具跑 git，不必再走「PowerShell 写临时文件再读」的老路。
- 本机 Git Bash 缺的 coreutils 不止三个：`ls` `head` `dirname` `grep` 全部 `command not found`（管道里用了会直接让整条命令 exit 127、连 git 输出都拿不到）。**Bash 工具只用来跑 git 子命令本身**，需要过滤/截断就改用 git 自有参数（`-n`、`--format`、`-<n>`）或 Grep 工具，不要在后面接 `| head` / `| grep`。
