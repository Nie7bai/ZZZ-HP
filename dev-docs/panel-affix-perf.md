## 当前这版还在的 bug（必须修）

这些和「快照提速」不是同一件事，但必须先做对，否则缓存会把错面板冻住。

### 1. 全队转模没按每个人自己的局外

切到维琳娜后，蕾米的「局外攻击转模」仍可能吃**当前编辑中**的局外，而不是蕾米自己那份。

展示侧已有 `slotExternalPanelsMap`（每人一份局外）。引擎 `computeFinalPanel` 也按 `sourceKey` 槽位读 `panelSourceValuesBySlot`。洞在**取值入口不统一**：有的路径拿了编辑中 live 面板，有的拿了残缺表。

### 2. 切到队友后转模吃残缺 `convertSlotPanels`

`convertSlotPanels` 只是「转模增益角色只填转模用到的几个属性」，不是完整局外。词条模式下，该槽应用**自己的词条 + 驱动盘**算出完整局外（`derivedExternalPanelForSlot` / 槽上的 `affixCounts`）。不能用残缺转模表去折「局外攻击转模」。

### 3. 招式结算（命中路径）没用每人那份局外

流程里给「不是正在编辑的人」取局外时，走了 `ensureAnomalySlotPanel` → `anomalySlotPanels`。

这张表的原意：面板模式下，异常参与者切走编辑后，把手填局外存一份。**不是**词条盘。所以词条模式下，招式持有者 / 强度提供者 / 触发者的局外可能和展示用的「每人一份」不是同一张，转模和伤害会对不上。

改法：展示、转模、招式结算、其他参与者局内，**全部**走同一个 `resolveExternalPanelForSlotIndex`。

词条模式：该槽 `affixCounts` + 盘算出局外。  
面板模式：正在编辑的人用 live 手填；其他人优先用已存的完整局外（`anomalySlotPanels`）；`convertSlotPanels` 不再充当完整局外。

### 4. 已在检查点里修好的（不再当新 bug）

- 主C 勾选带动面板：已去掉勾选，一律看编辑中槽位。

### 5. 明确先不动

- 蕾米本人耀变精通：实现仍是「局外精通 + 盘/音擎全局精通」；口径应是局内实时精通。见 `skill-flow-todo.md` D2。

## 面板概念（这次改造认的）

每人：

1. **局外**：对照游戏局外；词条只改这里。必须展示。
2. **临时局内**：局外 + 不限招式的非转模战斗增益（转模前）。
3. **全局局内（展示用最终）**：再加上转模（局外转模与局内转模同一轮，互不吃对方结果）。不含招式限定增益。

转模不是第三张快照：读该人局外或读该人临时局内，写出一项属性。

伤害：按这一击匹配招式限定增益后，再算这一击的局内。不写回展示用全局局内。

改词条：若该属性不是某条转模的「从」，局内就是同一套固定加成套到新局外上，`A+x` 线性变。有转模读这个属性，只重折那几条公式。

## 提速做法（不改存盘）

禁止：防抖推迟数字、把全队加成合成一份再套到别人身上。

允许：内存里按「增益目录」缓存已拆好的效果清单（影画/音擎/盘 clone 结果）。缓存键含编队、影画、音擎、盘、邦布、额外 Buff、勾选、招式上下文、当前结算槽位。**不含**词条数字、局外数值。

改词条时：

- 目录命中 → 不再扫角色文档。
- 非转模加成当常数，直接套新局外，得到新的临时局内。
- 只把转模效果用新的「该槽局外 / 临时局内」重算。
- `computeFinalPanel` 里同一轮不要再扫第三遍来源；`collectedEffects` 这条展示用不到的路径不再顺手全扫。

招式每一击仍按自己的招式上下文算（该有的）；同一人同一上下文不要重复拆目录。
